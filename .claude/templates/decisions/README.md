# 決定記録（Decision Records）

仕様や設計で検討・決定した内容を、1件につき1ファイルで残す。
一度書いた記録は基本的に書き換えない。決定を変える場合は、新しい記録を追加し、古い記録の状態を「置き換え済み」にする。

## 目次
- [ファイル名](#ファイル名)
- [一覧](#一覧)
- [テンプレート](#テンプレート)

## ファイル名
`連番4桁-内容を表す日本語.md`（例：`0012-画像の並び順は自然順.md`）。スペースは入れない

## 一覧
| 番号 | タイトル | 状態 | 日付 |
|---|---|---|---|

## テンプレート

```markdown
# 番号. タイトル

- 状態：提案中 / 採用 / 却下 / 置き換え済み（→ 番号） / 一部置き換え済み（→ 番号）
- 日付：YYYY-MM-DD

## 目次
- [背景](#背景)
- [検討した選択肢](#検討した選択肢)
- [決定](#決定)
- [理由](#理由)
- [影響](#影響)

## 背景
何を決める必要があったか。

## 検討した選択肢
- 案A：概要。良い点・悪い点
- 案B：概要。良い点・悪い点

## 決定
何に決めたか。

## 理由
なぜそれを選んだか。

## 影響
この決定によって変わること、今後注意すること。
```
